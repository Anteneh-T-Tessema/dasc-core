# Security Policy

## Supported Versions

DASC is committed to keeping the agentic ecosystem safe. We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability within DASC, please send an email to **security@dasc-safety.org** (or your preferred contact email).

We will acknowledge your report within 48 hours and provide a detailed timeline for a fix. We follow a coordinated disclosure model and will credit you for your find once the vulnerability is patched.

### Scope
- Bitemporal Ledger Tampering
- Policy Engine Bypass
- Unauthorized Action Commitment
- PII Sanitization Failures

Thank you for helping keep the DASC community safe!
